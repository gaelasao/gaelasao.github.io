About this data

Source: United States — Seattle building permits (SDCI). Published by City of Seattle Open Data, updated daily (publisher). Licence: Public Domain (publisher declaration). Values are the amounts declared on the application, not final costs.

  • Seattle only; not nationwide United States.
  • Issued permits as published by the city. Coverage, field meanings and update delays follow the publisher.
  • Project values are the amounts declared to the city, not final construction costs.

Questions

How often is Seattle permit data updated?

City of Seattle Open Data updates the open data daily (publisher). A run always reads the latest published records.

Can I get only some building permits?

Yes. Filter by date range, ZIP code, keyword in the description or type, and cap the number of records.
