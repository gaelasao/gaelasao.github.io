Questions

Where does the data come from?

From each city’s or government’s official open-data portal (Socrata, ArcGIS, CKAN or Carto). Every record keeps a link to its source and the licence.

Is the data the same format for every city?

Yes. Dates, status, type, address, value and contractor are mapped to the same field names, so you can mix cities in one sheet.

How fresh is it?

Most US portals update daily. Each run reads the portal live, so you get what the city has published so far.

Can I add a city?

Cities that publish permits as open data can be added. Ask through the tool’s Issues tab on Apify.
